## 火焰边框 Shader
- 创建 `assets/resources/effects/flame-frame.effect` — 常驻火焰边框效果
  - 原理：alpha 边缘检测 + alpha 模糊距离场 + 3 层 fbm 噪声模拟 flicker
  - 火焰仅在透明区域（精灵外边界）显示，不遮盖原图
  - 噪声 UV 纵向压缩（*0.45）产生自然火舌形状，cc_time 驱动上升动画
  - 颜色渐变：flameColorInner(亮黄根部) → flameColorOuter(红橙尖端)
  - 参数：flameHeight(1~20)、flameIntensity(0.2~4)、flameSpeed(0.2~5)、flameDetail(3~20)
  - 额外 20% 内发光 bleed 到精灵边缘
- 创建 `assets/scripts/effects/FlameFrame.ts` — 组件脚本，与 EdgeLuminescence 同架构
  - ⚠️ 注意：一个 Sprite 只能有一个 customMaterial，EdgeLuminescence 和 FlameFrame 二选一
