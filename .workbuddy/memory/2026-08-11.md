## Godot 2D Shader 效果分析
- 分析了 https://github.com/gdquest-demos/godot-shaders 中所有 2D shader 效果（17 个 canvas_item + 后处理）
- 逐个查看了 shader 源码、参数、算法原理
- 按迁移到 Cocos Creator 的难度和实用优先级做了分级
- 详细报告：`outputs/godot_2d_shaders_report.md`

### 结论
- 强烈建议迁移：PalettSwap2D（换色系统）、outline2D（描边）、dissolve2D（溶解）、clouds2D（云影）
- 云影效果与篮球场景天然契合，推荐优先尝试
- Godot shader → Cocos Effect 语法差异不大，核心算法完全可复用

## X光透视头像效果实现
- 创建 `xray-avatar-mask.effect`：横向扫描线扫过头像的 X 光透视效果
  - `sweepProgress` 控制扫描位置（0→1 左到右），扫描左侧完全显示、右侧变暗+蓝色 X 光色调
  - `sweepWidth` 过渡带宽度，`dimness` 暗度，`glowWidth` 扫描边缘发光衰减
  - 边缘使用指数衰减 `exp()` 产生光晕，比简单的 smoothstep 更自然
- 第一版错误地将测试逻辑写入了 `RecruitmentController.ts`，已全部回滚
- 最终方案：创建独立组件 `scripts/effects/XrayAvatarScan.ts`
  - 风格对齐项目现有 effect 组件（FrameFlow / EdgeLuminescence 等）
  - Effect 加载使用模块级单例缓存（`_effectAsset` + `_loadPromise`）
  - @property 全部可配置：duration / holdAfter / sweepWidth / dimness / glowFalloff / glowColor / xrayTint
  - `playOnLoad = true` 即可自动测试，或手动调用 `play()`
  - 新增 `loop` 模式（默认开启）：扫描循环播放，每轮间隔 `pauseDuration` 秒停顿后自动重启
  - 新增 `stop()` 方法：调用后立即停止扫描并清理材质
  - 循环模式下 Material 不销毁/重建，只重置 progress 并重启 tick

## 星月夜星空背景效果
- 分析 https://godotshaders.com/shader/starry-night/ — canvas_item 类型，可直接迁移
- 创建 `starry-night-bg.effect`：程序化星空，十字辉光主星 + 散布背景星 + 深色夜空底色
  - FRAGCOORD → `uv0 * nodeSize.xy`，SCREEN_UV → `uv0`，TIME → `cc_time.x`
  - 主星3层分辨率网格 + 十字辉光算法 + 渐变色映射
  - 背景星随机散布 + 独立闪烁
- 生成两张渐变色贴图 `gradient-star-a.png` / `gradient-star-b.png`（256×4，主星暖色渐变 + 背景星冷色渐变）
- 创建独立组件 `scripts/effects/StarryNightBg.ts`
  - 挂到招募结果页 `球员头像/bg` 节点即用
  - 所有 shader 参数暴露为 @property（主星/背景星/天色 三组）
  - 自动读取 UITransform 尺寸传入 nodeSize
  - 动画由 `cc_time` 驱动，组件无需 tick 循环
  - 挂到招募结果页 `球员头像/头像` 节点上，`playOnLoad` 勾上就能看到效果
