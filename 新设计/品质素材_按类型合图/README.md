# 球员品质素材按类型合图

这里的生产合图均为透明像素 PNG、无文字，九种品质视觉按 `00 → 08` 从左到右、从上到下排列；色彩和硬边以已确认的招募结果视觉母版为准。

## 项目中实际使用的七类品质素材

1. `01_招募背景_9品质合图.png`
2. `02_方头像框_9品质合图.png`
3. `03_圆头像框_9品质合图.png`
4. `04_细边框_9品质合图.png`
5. `05_品质标签_9品质合图.png`
6. `06_名牌_9品质合图.png`
7. `07_麦穗_9品质合图.png`

`00_按类型合图总览.png` 仅用于预览，带棋盘格背景；不要从总览图切正式素材。

`切图坐标.json` 记录每张生产合图的画布、单元格和素材实际坐标。

| 索引 | 品质 |
|---:|---|
| 00 | 概念神 |

GDD 的标准品质色是八组；当前代码额外把“概念神”映射到视觉索引 00，所以工程资源实际是 `00–08` 共九套。
