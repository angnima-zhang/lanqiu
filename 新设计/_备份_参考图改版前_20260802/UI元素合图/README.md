# 新原型 UI 元素合图

本目录将 `D:\篮球\新设计\新原型图` 中 12 张正式原型拆解为可复用、无动态文字的 UI 图片组件。

整套共 221 个可切图元素，分布在 8 张正式合图中。

## 合图清单

| 文件 | 主要内容 |
|---|---|
| `01_背景与面板_街球竞技.png` | 明暗街球背景、通用标题栏、信息/普通/品质/风险面板、弹窗主体、胜负结果骨架、数据行 |
| `02_按钮导航与交互状态.png` | 荧光绿/蓝/橙/红/白/禁用按钮、返回/关闭/设置、底部导航、管理页签、开关、焦点框、视频与金币操作 |
| `03_数据进度与状态组件.png` | OVR、属性行、连续/分段进度、节比分、比赛事件、状态胶囊、对比/升级/累计/消耗/招募概率行 |
| `04_九档球员品质组件总表.png` | 0–8 档方框、圆框、细框、名牌、品质标签、麦穗、招募背景、概率行边框 |
| `05_球员卡片与阵容槽位.png` | 普通/高品质/GOAT 卡壳、详情大卡、方/圆空槽、替换与最佳球员底板、列表卡与角标 |
| `06_比赛HUD与赛果组件.png` | 我方/敌方球队牌、节比分、球场视窗、事件流、比赛操作、胜负骨架、奖励与赛后按钮 |
| `07_弹窗奖励与系统面板.png` | 球队信息/离线收益/设置弹窗、收益与奖励行、开关、最佳球员、总评框、关闭与编辑 |
| `08_功能与属性图标.png` | 管理层、五项数据、系统、比赛、结果、交互、阵营和状态形状图标 |

`00_UI元素合图总览.png` 用于快速审阅；`切图坐标.json` 给出每个元素在合图中的像素坐标与尺寸。

## 使用约束

- 8 张正式合图均为 2048×2048 RGBA PNG，四角与元素间背景为纯白。
- 合图不包含球员名、球队名、数值、按钮文字等动态内容；这些内容继续使用 Cocos Label。
- 同一种颜色含义同时保留形状、边框或图标编码，例如我方/敌方、正常/危险、胜利/失败不依赖颜色单独区分。
- 按钮已拆出常态、主操作、次操作、危险、禁用、视频、金币、选中页签、开关与焦点状态。
- 品质总表是切图预览；完整原始尺寸的九档品质资源仍位于 `D:\篮球\新设计\品质素材_9档` 和 `D:\篮球\新设计\品质素材_按类型合图`。
- 本次仅生成设计产物和生成脚本，没有修改 Cocos 工程内的 Prefab、节点、UUID、代码或现有图片。

生成脚本：`D:\篮球\tools\generate_new_prototype_ui_element_sheets.py`
