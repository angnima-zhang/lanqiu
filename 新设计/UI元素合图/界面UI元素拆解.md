# 12 个界面的 UI 元素拆解

## 主页

- 背景：明亮街球背景。
- 顶部：球队信息标题栏、设置按钮、状态提示条。
- 核心：球场视窗、球员方卡槽、管理层小卡、球队等级进度。
- 底部：五入口导航的普通与选中状态、主操作按钮。
- 对应合图：01、02、03、05、08。

## 备赛

- 顶部：返回标题栏、赛程场次、我方/敌方总评牌。
- 中部：双方阵容列表卡、球员头像槽、管理层加成卡。
- 底部：主操作按钮。
- 对应合图：01、02、03、05、06、08。

## 比赛

- 顶部：我方/敌方球队牌、大比分、四节比分面板。
- 中部：球场视窗、比赛事件普通/当前状态。
- 底部：倍速、跳过、广告立即获胜。
- 对应合图：02、03、06、08。

## 球员详情

- 顶部：返回标题栏。
- 核心：GOAT/其它品质大卡、品质角标、名牌、OVR 面板。
- 数据：五项属性行、累计次数和效力时长行。
- 对应合图：01、03、04、05、08。

## 管理层

- 顶部：返回标题栏、预算区域。
- 导航：运营、教练、球探、队医、媒体页签的普通/选中态。
- 核心：管理成员展示卡、等级进度、当前/下一级效果、升级消耗。
- 操作：普通升级与广告免费升级。
- 对应合图：01、02、03、05、08。

## 球队信息

- 背景：深色模态遮罩。
- 弹窗：大型蓝绿标题弹窗、关闭按钮。
- 内容：可编辑输入底板、球队总评、最佳球员行、累计胜场、保存按钮。
- 对应合图：01、02、03、04、05、07、08。

## 离线收益

- 背景：深色模态遮罩。
- 弹窗：中型蓝绿标题弹窗、关闭按钮。
- 内容：离线时长、基础收益、媒体加成、金币奖励行。
- 操作：普通领取、广告双倍领取。
- 对应合图：02、03、07、08。

## 设置

- 背景：深色模态遮罩。
- 弹窗：小型蓝绿标题弹窗、关闭按钮。
- 内容：音乐/音效设置行、开启/关闭开关。
- 对应合图：02、07、08。

## 胜利

- 背景：深色模态遮罩。
- 弹窗：冠军奖杯结果骨架、赛程/比分区、奖励行。
- 操作：广告加倍领取、返回、继续下一场。
- 对应合图：02、03、06、07、08。

## 失败

- 背景：深色模态遮罩。
- 弹窗：橙色失败结果骨架、赛程/比分区。
- 操作：广告重新挑战、调整阵容。
- 对应合图：02、03、06、08。

## 招募概率

- 背景：深色模态遮罩。
- 弹窗：招募概率标题壳、关闭按钮。
- 品质：九档概率行底板/边框与品质标签。
- 操作：球探等级信息、升级球探主按钮。
- 对应合图：01、02、03、04、08。

## 招募结果

- 背景：街球竞技结果背景。
- 核心：品质招募背景、球员卡壳、方框/角标/名牌、OVR。
- 数据：五项属性行、被替换球员小卡、总评提升。
- 操作：解雇、替换上阵、广告升级。
- 对应合图：01、02、03、04、05、08。
